## 已完成能力

### 文档与计划

- 已整理产品说明、架构说明、MVP 计划和演示脚本。
- 已在架构文档中对齐 MS1 检查项。

### 后端基础

- FastAPI 后端骨架已建立。
- 健康检查接口已可用。
- 事项、提醒、地点、写请求、领域事件等核心模型已建立。
- Alembic / SQLAlchemy 迁移结构已存在。
- 后端测试可运行，最近一次验证结果为 `27 passed, 1 warning`。

### 事项与写入流程

- 支持手动新增事项。
- 支持通过真实 ASR + LLM 语音命令生成候选写入请求。
- 未配置外部 LLM 时可降级到本地关键词解析。
- 写操作已经走 `WriteRequest` 确认门禁。
- 支持创建、修改、删除、完成事项等基础操作路径。

### 数据库与语音实联调

- 已使用真实 Supabase Postgres 执行 Alembic 迁移。
- API 运行时已使用 SQLAlchemy 持久化到 Supabase。
- 已接入 DeepSeek OpenAI 兼容接口进行结构化命令解析。
- 已接入阿里云 Qwen3-ASR-Flash，通过 Base64 音频完成中文转写。
- Swagger 已支持上传音频，并完成“转写 -> 解析 -> 确认 -> 日历事项落库”闭环。
- 前端录音已接入音频上传接口，识别后自动回填转写并进入确认流程。

### 提醒能力

- 时间提醒模型和投递状态已建立。
- 支持提醒状态回传和提醒动作。
- 支持地点提醒数据模型。
- 支持进入地点、离开地点、返回地点等提醒类型的基础规则。
- 前端已有地点提醒触发检查能力。

### 重复规则

- 支持 `daily`、`weekdays`、`custom_weekdays`。
- 已校验 `time_of_day`、weekday 取值、series 状态等字段。
- 前后端都已覆盖重复规则校验。

### 同步与离线

- 已建立 WebSocket 同步骨架（P0 直接同步广播，未引入持久化 Outbox）。
- 前端支持 WebSocket 重连。
- 支持 `sync.request` 断线后回补事件。
- 前端已有本地缓存。
- 已实现单设备 LWW 缓存合并。
- 已实现 quick add 离线队列：离线时先本地保存 quick add，恢复网络后自动重放到后端。

### 权限与降级

- 前端已有设备权限中心。
- 通知、定位、麦克风等权限状态已有 UI 承载。
- 后端已有稳定错误码和降级路径基础。

### 云端兜底

- 已实现最小可用 `CloudFallbackPolicy`。
- 本地通知注册失败后可生成 fallback request。
- 已增加 fallback request 相关测试。

### 接口文档入口

- 前端已增加 Swagger 入口。
- 后端 FastAPI 自带 Swagger，可通过 `/docs` 查看。
